# وب‌سایت شرکتی و پنل مدیریت «مدبر»

این سامانه یک وب‌سایت شرکتی مدرن، کاملاً واکنش‌گرا و راست‌چین (RTL) همراه با پنل مدیریت ۴ تب، فرم ثبت درخواست همکاری با ارسال ایمیل و پیوست رزومه، و ساختار امن بر پایه زبان PHP خام (بدون وابستگی به فریم‌ورک‌ها) می‌باشد.

---

## ۱. ساختار پوشه‌ها و معماری پروژه

```text
modabber/
├── app/                        # هسته نرم‌افزار (خارج از روت عمومی وب)
│   ├── .htaccess               # مسدودسازی دسترسی مستقیم وب به پوشه app
│   ├── config/config.php       # تنظیمات مرکزی و مقادیر محیطی
│   ├── core/                   # ماژول‌های امنیتی، سشن، دیتابیس، آپلود و ایمیل
│   ├── repositories/           # کلاس‌های دسترسی به داده (PDO)
│   ├── views/                  # لایه‌ها، صفحات و قالب‌های ایمیل
│   └── storage/                # لاگ‌ها و سشن‌های سرور
├── public/                     # روت وب سرور (قابل انتقال به public_html)
│   ├── .htaccess               # قوانین بازنویسی URL، هدرهای امنیتی و خطاها
│   ├── .user.ini               # محدودیت‌های حجم آپلود PHP
│   ├── index.php               # صفحه اصلی
│   ├── project.php             # صفحه جزییات پروژه
│   ├── project-apply.php       # دریافت و ارسال درخواست همکاری با رزومه
│   ├── login.php               # ورود به پنل مدیریت
│   ├── error.php               # صفحات خطای ۴۰۴، ۴۰۳ و ۵۰۰
│   ├── router.php              # روتر وب‌سرور داخلی PHP
│   ├── panel/                  # کنترلرهای ۴ گانه پنل مدیریت
│   ├── assets/                 # فایل‌های CSS، جاوااسکریپت و تصاویر
│   └── uploads/                # فایل‌های آپلود شده با پسوندهای امن
├── database/
│   ├── schema.sql              # ساختار جداول MySQL و تنظیمات اولیه
│   └── sample_data.sql         # داده‌های نمونه پروژه‌ها و لوگوها
├── scripts/
│   ├── create_admin.php        # ایجاد حساب کاربری مدیر از طریق CLI
│   └── test_mail.php           # آزمون صحت تنظیمات SMTP و ارسال ایمیل
└── README.md
```

## ۲. راه‌اندازی و ایجاد مدیر اولیه (CLI)

برای امنیت کامل، هیچ کاربر مدیری به صورت پیش‌فرض در دیتابیس وجود ندارد. جهت ایجاد اولین حساب مدیر، دستور زیر را در ترمینال اجرا کنید:

```bash
php scripts/create_admin.php
```

این اسکریپت نام کاربری، نام و نام خانوادگی، ایمیل و رمز عبور (حداقل ۱۰ کاراکتر با تکرار) را دریافت کرده و با الگوریتم Argon2id / Bcrypt رمزنگاری می‌نماید.

---

## ۳. فونت وزیرمتن (Vazirmatn)

فایل‌های فونت به صورت خودمیزبان (Self-hosted) فراخوانی می‌شوند. فایل‌های زیر را از گیت‌هاب رسمی Vazirmatn دانلود کرده و درون پوشه `public/assets/fonts/` قرار دهید:

- `Vazirmatn-Regular.woff2` (وزن ۴۰۰)
- `Vazirmatn-Medium.woff2` (وزن ۵۰۰)
- `Vazirmatn-Bold.woff2` (وزن ۷۰۰)
- `Vazirmatn-ExtraBold.woff2` (وزن ۸۰۰)

## ۴. تنظیمات ایمیل و آزمون ارسال

تنظیمات ایمیل در فایل `app/config/config.php` قرار دارد. مقادیر زیر را با اطلاعات سرور SMTP خود جایگزین کنید:

- `MAIL_DRIVER`: مقدار `'smtp'` (پیشنهادی) یا `'mail'`
- `MAIL_HOST`: آدرس سرور SMTP (مثال: `'mail.yourdomain.com'`)
- `MAIL_PORT`: درگاه ارسال (معمولاً `587` برای TLS یا `465` برای SSL)
- `MAIL_ENCRYPTION`: نوع رمزنگاری (`'tls'` یا `'ssl'`)
- `MAIL_USERNAME` و `MAIL_PASSWORD`: اطلاعات احراز هویت
- `MAIL_TO_ADDRESS`: ایمیلی که فرم درخواست‌های همکاری را دریافت می‌کند.

برای تست ارسال ایمیل، دستور زیر را در خط فرمان اجرا کنید:

```bash
php scripts/test_mail.php
```

---

## ۵. تنظیمات سرور و محدودیت‌های آپلود PHP

برای اطمینان از ارسال فایل‌های رزومه تا سقف ۵ مگابایت، مطمئن شوید مقادیر زیر در فایل `php.ini` یا `public/.user.ini` فعال باشند:

- `upload_max_filesize = 6M`
- `post_max_size = 8M`
- `max_file_uploads = 5`
- `memory_limit = 128M` (یا بیشتر)
